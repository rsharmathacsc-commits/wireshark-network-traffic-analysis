Task 5: Capture and Analyze Network Traffic Using Wireshark

Objective:

Capture live network packets using Wireshark and identify common network protocols.

Tools Used:
- Wireshark

Procedure: 

1. Installed Wireshark.
2. Started packet capture on the active Wi-Fi interface.
3. Generated network traffic by browsing websites.
4. Captured packets for approximately one minute.
5. Applied protocol filters.
6. Identified DNS, TCP, and ARP protocols.
7. Saved the capture as a .pcapng file.

Protocols Identified:

DNS (Domain Name System):
- Resolves domain names into IP addresses.

TCP (Transmission Control Protocol):
- Provides reliable communication between devices.

ARP (Address Resolution Protocol):
- Maps IP addresses to MAC addresses within a local network.

Conclusion: 

Successfully captured and analyzed live network traffic using Wireshark and identified multiple network protocols.
